Expenses

Expenses

Applies to: All tiers (Free, Pro, Business, Enterprise).

Manage the expenses you track in ExpenseFlow — create them by hand, edit details, and keep them organized under My Expenses.

How do I create a new expense?

  1. Go to My Expenses.
  2. Select New Expense.
  3. Enter the amount, date, category, and a short description.
  4. Attach a receipt if you have one (see Receipts).
  5. Select Save.
On mobile: tap the ⊕ button in the bottom navigation instead of "New Expense".

How do I edit an existing expense?

  1. Go to My Expenses.
  2. Select the expense you want to change.
  3. Update the fields you need to change.
  4. Select Save.

How do I categorize an expense?

  1. Open the expense from My Expenses.
  2. Select the Category field.
  3. Choose the category that best matches the expense (e.g. Meals, Travel, Supplies).
  4. Select Save.

How do I delete an expense?

  1. Open the expense from My Expenses.
  2. Select Delete.
  3. Confirm the deletion.
Deleted expenses are removed from active lists but may still appear in the Archive depending on your account settings.
