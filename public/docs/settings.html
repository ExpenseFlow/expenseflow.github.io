Settings

Applies to: All tiers (Free, Pro, Business, Enterprise). The Approvers section requires Business or Enterprise (see Approvals).

Configure your vehicles, approvers, contacts, notifications, and subscription.

How do I add a vehicle?

  1. Go to Settings → Vehicles.
  2. Select Add Vehicle.
  3. Enter the make, model, and year (used for mileage-rate calculations).
  4. Select Save.

How do I set up an approver?

  1. Go to Settings → Approvers.
  2. Select Add Approver.
  3. Enter their name and email.
  4. Select Save.

They can now be selected when you submit an expense for approval.

How do I manage notification preferences?

  1. Go to Settings → Notifications.
  2. Toggle the notification types you want to receive (e.g. approval updates, weekly summaries).
  3. Changes save automatically.

How do I manage my contacts?

  1. Go to Settings → Contacts.
  2. Select Add Contact to add a new one, or select an existing contact to edit or remove it.

How do I view or change my subscription?

  1. Go to Settings → Subscription.
  2. Review your current plan and billing details.
  3. Select Change Plan or Manage Billing to make changes.
