Trips & Mileage

Applies to: All tiers (Free, Pro, Business, Enterprise). Free is limited to 5 auto-tracked trips/month; Pro and above are unlimited.

ExpenseFlow tracks mileage two ways: automatic trips captured by GPS in the background, and manual trips you enter yourself. Both roll up into your Mileage Entries.

How do I let ExpenseFlow track my trips automatically?

  1. Install and open the mobile app.
  2. Grant location permission when prompted (choose "Always Allow" so tracking continues in the background).
  3. Drive as normal — tracking starts automatically once movement is detected.
  4. Check Automatic Trips afterward to review what was captured.
Automatic tracking is a mobile-only feature — it isn't available in the web app.

How do I review and classify an automatic trip?

  1. Go to Automatic Trips.
  2. Select a trip from the list.
  3. Mark it as Business or Personal, and adjust the purpose/category if needed.
  4. Select Save.

How do I add a trip manually?

  1. Go to Manual Trips.
  2. Select Add new trip.
  3. Enter the start and end locations (or distance directly), date, and purpose.
  4. Select Save.
Use manual trips for drives that happened before you installed the app, or when GPS tracking wasn't available.

How do I view all my mileage entries?

  1. Go to Mileage Entries.
  2. This combines both automatic and manual trips into a single list, with distance and computed deduction value.
  3. Select any entry to see its details or make edits.

How do I fix a trip with the wrong distance?

  1. Open the trip from Automatic Trips or Manual Trips.
  2. Select Edit.
  3. Adjust the distance or route as needed.
  4. Select Save.
