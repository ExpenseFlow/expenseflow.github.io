Approvals

Approvals

Applies to: Business and Enterprise tiers only. Approval workflows are not available on Free or Pro.

Route expenses through an approver before they're finalized — useful for teams and shared accounts.

How do I submit an expense for approval?

  1. Open the expense from Expenses.
  2. Select Submit for Approval.
  3. Choose the approver (configured under Settings → Approvers).
  4. Select Submit.

How do I check the status of my approval requests?

  1. Go to Approval Requests.
  2. Each request shows its current status: Pending, Approved, or Rejected.
  3. Select a request to see the approver's comments, if any.

How do I approve or reject a request (as an approver)?

  1. Go to Approval Requests.
  2. Select the pending request you want to review.
  3. Review the expense details and attached receipt.
  4. Select Approve or Reject, adding a comment if you're rejecting.

How do I resubmit a rejected expense?

  1. Open the rejected expense.
  2. Address the approver's comments (e.g. adjust the amount, attach a missing receipt).
  3. Select Submit for Approval again.
